# ============================================================================
#  OIDA-SQL  -  Wörterbuch
# ============================================================================
#
#  Links steht das MySQL-Wort, rechts schreibst du dein Wort hin:
#
#      CREATE = ERSTÖN
#
#  Regeln:
#   - Rechts leer lassen  ->  das Wort bleibt englisch.
#   - Mehrere Varianten mit Beistrich:      SELECT = GIB MA, ZAG MA
#   - Rechts dürfen mehrere Wörter stehen:  DELETE = SCHLEICH DI
#   - Du kannst eigene Zeilen dazuschreiben, auch mit mehreren Wörtern links:
#                                           ORDER BY = DA REIH NOCH
#   - Steht rechts auch das englische Wort selbst (INDEX = VERZEICHNIS, INDEX),
#     dann bleibt das englische Wort zusätzlich erlaubt.
#   - Groß-/Kleinschreibung ist egal (erstön = ERSTÖN = Erstön).
#   - Zeilen mit # am Anfang sind Kommentare.
#   - Ein Dialekt-Wort darf nur bei EINEM MySQL-Wort stehen
#     (sonst meldet bauen.bat einen Fehler und sagt dir, welches).
#
#  Achtung bei Wörtern, die auch als Spalten- oder Tabellenname vorkommen
#  (VON, ENDE, WERTE ...): als Name in Backticks schreiben, z.B. `von`.
#
#  Nach dem Ändern:  bauen.bat  doppelklicken  ->  oida-sql.jar ist neu.
#  Diese Datei als UTF-8 speichern (wegen Ö, Ä, Ü, ß).
#
# ============================================================================
