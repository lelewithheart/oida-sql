Das ist ganz normales MySQL, nur heißen die Wörter anders. Ein kleiner Treiber übersetzt jeden Befehl, bevor er zur Datenbank geht. Du brauchst nur DataGrip und eine MySQL-Datenbank.

Einrichten

Einmal machen, dauert drei Minuten. DataGrip holt sich alles von dieser Adresse, auch spätere Updates:

https://lelewithheart.github.io/oida-sql/updatePlugins.xml
A

Plugin

kommt von der Adresse oben
  1. Settings (Strg Alt S) → Plugins
  2. Zahnrad oben → Manage Plugin Repositories…
  3. + klicken, die Adresse einfügen, OK
  4. Reiter Marketplace: nach OIDA-SQL suchen, Install
  5. DataGrip neu starten

Updates meldet DataGrip danach von selbst. Nach dem Neustart sind auch Treiber und Wörterbuch neu.

B

Treiber

hat das Plugin schon mitgebracht
  1. File → Data Sources…, links oben der Reiter Drivers
  2. MySQL anklicken und duplizieren (Strg D). Die Kopie OIDA-SQL nennen.
  3. Bei Driver Files: + → Custom JARs… → in deinem Benutzerordner .oida-sql → oida-sql.jar
  4. Bei Class auswählen:
    at.oida.OidaDriver
  5. Apply
C

Verbindung

wie bei normalem MySQL
  1. File → Data Sources… → + → OIDA-SQL
  2. Host, Port, User und Passwort eintragen
  3. Test Connection, dann OK

Die Adresse bleibt jdbc:mysql://…, nur der Treiber ist ein anderer.

Probier’s aus: Konsole öffnen, HERZAGN DE TABÖN OIDA eintippen, Cursor in die Zeile, Strg Enter. Das ist SHOW TABLES.

Benutzen und die wichtigsten Wörter

So geht’s

  • Befehl schreiben, Cursor hinein, Strg Enter.
  • Am Ende von jedem Befehl steht OIDA. Einen Strichpunkt brauchst du nicht.
  • Tippst du MySQL, wird es gleich übersetzt: Aus SELECT wird beim Leerzeichen GIB MA. Beim Einfügen auch.
  • Die Vorschlagsliste kennt die Dialekt-Wörter. Du findest sie auch über das englische Wort.
  • Groß- und Kleinschreibung ist egal: gib ma geht genauso.
  • Heißt eine Spalte wie ein Dialekt- oder MySQL-Wort (von, date), dann in Backticks: `von`
