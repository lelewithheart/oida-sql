OIDA-SQL

MySQL, aber im Dialekt. Und am Schluss sagst OIDA.

ERSTÖN TABÖN leit (id ZOI ZÖHT SÖWA MIT HAUPTSCHLISSL, name KETTN(50)) OIDA;
EINEHAUN IN leit (name) WERTE ('Franz'), ('Resi') OIDA;
GIB MA name VON leit WO name SO WIA 'F%' OIDA;
GUSCH DI TABÖN leit OIDA;

Das ist ganz normales MySQL, nur heißen die Wörter anders. Ein kleiner Treiber übersetzt jeden Befehl, bevor er zur Datenbank geht. Du brauchst DataGrip und eine MySQL-Datenbank.

Einrichten

DataGrip holt sich alles von dieser Adresse, auch spätere Updates:

Aktuelle Version wird geladen …

APlugin

  1. Settings (Strg+Alt+S) → Plugins
  2. Zahnrad oben → Manage Plugin Repositories…
  3. + klicken, die Adresse einfügen, OK
  4. Reiter Marketplace: nach OIDA-SQL suchen, Install
  5. DataGrip neu starten

BTreiber

Den Treiber hat das Plugin schon mitgebracht.

  1. File → Data Sources…, links oben der Reiter Drivers
  2. MySQL anklicken und duplizieren (Strg+D). Die Kopie OIDA-SQL nennen.
  3. Bei Driver Files: + → Custom JARs… → in deinem Benutzerordner .oida-sql → oida-sql.jar
    Unter Windows: C:\Users\DEINNAME\.oida-sql\oida-sql.jar
  4. Bei Class auswählen: at.oida.OidaDriver
  5. Apply

CVerbindung

  1. File → Data Sources… → + → OIDA-SQL
  2. Host, Port, User und Passwort eintragen wie bei normalem MySQL
  3. Test Connection, dann OK

Probier’s aus: Konsole öffnen, HERZAGN DE TABÖN OIDA; eintippen, Cursor in die Zeile, Strg+Enter. Das ist SHOW TABLES.

Updates

Kommen von selbst. DataGrip meldet bei den Plugins, wenn es eine neue Version gibt. Nach dem Update und einem Neustart sind auch Treiber und Wörterbuch neu.
