OIDA-SQL
========

MySQL, aber im Dialekt. Jeder Befehl muss mit OIDA aufhören.

    ERSTÖN TABÖN leit (id ZOI ZÖHT SÖWA MIT HAUPTSCHLISSL, name KETTN(50)) OIDA;
    EINEHAUN IN leit (name) WERTE ('Franz'), ('Resi') OIDA;
    GIB MA * VON leit WO name SO WIA 'F%' OIDA;
    GUSCH DI TABÖN leit OIDA;

Du brauchst nur DataGrip und eine MySQL-Datenbank. Herunterladen musst du nichts,
DataGrip holt sich alles von dieser Adresse:

    https://lelewithheart.github.io/oida-sql/updatePlugins.xml


EINRICHTEN (einmal, ca. 3 Minuten)
----------------------------------

A) Plugin

  1. Settings (Strg+Alt+S) -> Plugins
  2. Zahnrad oben -> "Manage Plugin Repositories..."
  3. + klicken, die Adresse von oben einfügen, OK
  4. Reiter "Marketplace": nach OIDA-SQL suchen, Install
  5. DataGrip neu starten

B) Treiber (hat das Plugin schon mitgebracht)

  1. File -> Data Sources...  ->  links oben Reiter "Drivers"
  2. "MySQL" anklicken und duplizieren (Strg+D). Die Kopie "OIDA-SQL" nennen.
  3. Bei "Driver Files" auf +  ->  "Custom JARs..."  ->  in deinem Benutzerordner
     den Ordner .oida-sql  ->  oida-sql.jar
     (unter Windows:  C:\Users\DEINNAME\.oida-sql\oida-sql.jar)
  4. Bei "Class" auswählen:  at.oida.OidaDriver
  5. Apply

C) Verbindung

  1. File -> Data Sources... -> +  ->  "OIDA-SQL"
  2. Host, Port, User, Passwort eintragen wie bei einer normalen MySQL-Verbindung
  3. Test Connection, OK


UPDATES
-------

Kommen von selbst. DataGrip meldet bei den Plugins, wenn es eine neue Version gibt.
Nach dem Update und einem Neustart sind auch Treiber und Wörterbuch neu.


BENUTZEN
--------

Konsole öffnen, Befehl schreiben, Cursor hinein, Strg+Enter.

  - Am Ende von jedem Befehl:  OIDA;
  - Englisch geht nicht mehr. Wer SELECT schreibt, bekommt gesagt, wie es richtig heißt.
  - Groß- und Kleinschreibung ist egal.
  - Heißt eine Spalte wie ein Dialekt-Wort (z.B. von), dann in Backticks: `von`


DIE WICHTIGSTEN WÖRTER
----------------------

  SELECT      GIB MA / ZAG MA        CREATE      ERSTÖN
  FROM        VON                    TABLE       TABÖN
  WHERE       WO                     DROP        GUSCH DI / ZAMHAUN
  AND / OR    UND / ODA              ALTER       ÄNDER
  NOT         NED                    INSERT      EINEHAUN
  NULL        NUI / NIX              INTO        IN
  AS          OIS / HAASST           VALUES      WERTE
  JOIN        ZAMQUETSCHN            UPDATE      AKTUALISIERN
  ON          AUF                    SET         SETZN
  LEFT        LINKS                  DELETE      SCHLEICH DI
  GROUP BY    NIMM ZOM NOCH          PRIMARY KEY HAUPTSCHLISSL
  HAVING      DER HOT                FOREIGN KEY FREMDSCHLISSL
  ORDER BY    DA REIH NOCH           REFERENCES  ZAGT AUF
  ASC / DESC  AUFFE / OWE            NOT NULL    MUASS SEI
  LIMIT       HÖCHSTENS              AUTO_INCREMENT  ZÖHT SÖWA MIT
  DISTINCT    EINZIGOATIG            INT         ZOI
  LIKE        WIA / SO WIA           VARCHAR     KETTN
  IN          DRINNA                 DATE        TOG
  BETWEEN     DAZWISCHN              BOOLEAN     JONA
  EXISTS      GIBTS                  TRUE/FALSE  WOAHR / FOISCH
  COUNT       WIAVÜ / ZÖH            SHOW TABLES HERZAGN DE TABÖN
  SUM         ZAMZÖHN                USE         NIMM
  AVG         IM SCHNITT             DESCRIBE    WOS IS
  MIN / MAX   KLANSTA / GRÖSSTA      COMMIT      DES BLEIBT SO
  UPPER       SCHREI                 ROLLBACK    DES WOA NIX
  LOWER       FLÜSTER                START TRANSACTION   GEMMA

Alle Wörter:  https://lelewithheart.github.io/oida-sql/Woerterbuch.pdf

Du weißt ein Wort nicht? Schreib es englisch hin und führ den Befehl aus,
die Fehlermeldung sagt dir das richtige Wort.
